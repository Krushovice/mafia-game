# Мафия: Диспетчер Империи — Руководство для Claude

## Концепция игры

Telegram Mini App (TMA) в жанре стратегии/менеджмента. Игрок — мафиозный босс в городе **Сан-Марчелло**. Эстетика: тёмная, но не мрачная — стиль Empire of Sin. Миссии всплывают на карте как в Dispatch.

Игрок начинает с одного района (Уэст-Энд) и постепенно захватывает город, отправляя бойцов на миссии, управляя ресурсами и уклоняясь от облав.

## Игровые механики (канонические)

### Ресурсы
| Ресурс | Описание |
|---|---|
| 💰 Мафия Коины | Основная валюта, тратится на нанём, снаряжение |
| 🌐 Влияние | Накапливается с миссий, нужно для захвата районов |
| ⚠️ Розыскиваемость | Растёт от миссий, замедляет игру при высоком значении |

### Миссии
- **Лёгкая** — 1 слот для бойца
- **Средняя** — 2 слота
- **Тяжёлая** — 3 слота (захват района всегда тяжёлая)
- Предметы повышают шанс успеха: оружие, инвентарь для ограблений, лицензии и т.д.
- `mission_type`: `regular` | `flash` | `territory`

### Антигрнд-механики
1. **Розыск**: после 4-5 миссий подряд растёт wanted_level → нужно ждать реальное время для снижения. Снизить за деньги — только если розыск < 80.
2. **Кулдаун влияния**: после захвата района влияние не накапливается 12-24 ч.
3. **Усталость бойцов**: после 3 миссий подряд боец отдыхает 30-60 мин (запланировано, не реализовано).

### Облавы (события)
**Копы:**
- Откуп (не работает при высоком розыске)
- Заговорить зубы (шанс растёт с влиянием)
- Игнор (потеря влияния)

**Другая мафия (NPC):**
- Бой (влияние + оружие у бойцов)
- Заговорить зубы
- Игнор (потеря монет и влияния)

### Flash-миссии
Появляются раз в 4-6 ч, живут 2 часа, награда x2-3. Telegram-уведомление при появлении. Тип `mission_type = 'flash'` уже есть в `frontend/src/types.ts`.

### Ежедневные задания (запланировано)
3 задания в день: "проведи 2 миссии", "собери 500 монет", "не попадись копам". Бонус: редкий предмет или монеты.

### Монетизация (без P2W)
| Что | Тип |
|---|---|
| Сброс розыска (только если < 80) | Удобство |
| Косметика районов (цвет, иконка) | Косметика |
| Скины/портреты бойцов | Косметика |
| Особый титул в профиле (Дон, Крёстный отец) | Косметика |
| Быстрый наём (пропуск 30-мин кулдауна) | Удобство |

### PvP (на потом — не реализовывать сейчас)
Атаки других мафий сейчас — только NPC боссы. PvP между реальными игроками — отдельный этап.

## Конвенции кода

### Бэкенд
- Весь новый код — async/await
- Сервисный слой содержит бизнес-логику, роутеры — только валидацию и вызов сервиса
- Транзакции открывать в сервисах, не в роутерах
- Pydantic схемы для всех входящих/исходящих данных API

### Фронтенд
- Архитектура FSD: imports только сверху вниз (pages → widgets → features → entities → shared)
- Глобальные типы — `src/types.ts`
- API-вызовы — только через `src/api/client.ts`
- Стейт сервера — TanStack Query, UI-стейт — zustand

### Общее
- Все текстовые файлы проекта (документация, комментарии в коде) — на **русском языке**
- Промпты для генерации изображений — на английском (требование нейросетей)
- Скиллы Claude хранятся в `.claude/skills/`
