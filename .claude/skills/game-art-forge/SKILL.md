# Game Art Forge — Кузница Игрового Арта

Создаёт новый игровой арт в объединённом стиле референсных изображений: Claude Vision извлекает визуальную ДНК, Pollinations.ai (бесплатно, без API-ключа) генерирует несколько вариантов.

## Что делает этот скилл

1. **Анализирует** каждый референс через Claude Vision — стиль, палитра, настроение, сеттинг, визуальные элементы
2. **Синтезирует** детальный промпт, смешивая все референсы в единый стиль
3. **Генерирует** несколько вариантов изображений через Pollinations.ai
4. **Сохраняет** все варианты локально и показывает что получилось

## Входные данные

Аргументы передаются через `$ARGUMENTS`. Разбери их как пути к файлам или URL через пробел, плюс необязательное текстовое описание в конце (всё что не похоже на путь или URL — это описание).

**Примеры:**
```
/game-art-forge screenshot1.png screenshot2.jpg "улица города ночью"
/game-art-forge /путь/к/ref1.png /путь/к/ref2.png
/game-art-forge https://example.com/game.jpg "портрет персонажа"
```

Если аргументы не переданы — попроси пользователя предоставить хотя бы одно референсное изображение.

## Шаг 1: Анализ каждого референса

Для каждого пути/URL прочитай или загрузи изображение и проанализируй его через vision. Для каждой картинки извлеки:

- **Стиль арта**: пиксель-арт / рисованный / 3D-рендер / нуар / живописный / cel-shaded / реалистичный / стилизованный / и т.д.
- **Цветовая палитра**: доминирующие цвета, насыщенность, тёплая/холодная/нейтральная гамма, заметные цветовые сочетания
- **Настроение и атмосфера**: мрачный/гритти, яркий, меланхоличный, напряжённый, таинственный и т.д.
- **Сеттинг и тема**: какому миру принадлежит? (криминальный город, фэнтези, sci-fi и т.д.)
- **Визуальные элементы**: какие объекты, персонажи, окружение, текстуры присутствуют
- **Технические детали**: стиль освещения, перспектива, уровень детализации, отличительные приёмы

Кратко подведи итог для пользователя, например:
> "По 3 референсам вижу: мрачная нуар-эстетика города, приглушённые синие и янтарные тона, рисованный стиль с видимыми мазками, кинематографичная перспектива."

## Шаг 2: Составление промпта для генерации

Объедини все извлечённые элементы в единый насыщенный английский промпт, оптимизированный под Flux/Stable Diffusion. Промпт должен:

- Начинаться с наиболее характерных стилевых дескрипторов
- Содержать конкретные описания цветов (не просто "тёмный", а "desaturated slate blues, amber highlights")
- Конкретно описывать настроение и сеттинг
- Заканчиваться усилителями качества: `masterpiece, highly detailed, concept art, game art`
- Не допускать противоречий между стилями разных референсов — смешивай, не перечисляй конфликтующие стили рядом

Также подготовь **негативный промпт**: `blurry, low quality, watermark, signature, ugly, deformed, NSFW`

Если пользователь передал текстовое описание в аргументах — включи его как тему/сцену.

Если описание не задано — придумай что-то подходящее под сеттинг (например для криминального города: угол улицы ночью, тёмный переулок, персонаж в плаще).

Покажи пользователю итоговый промпт перед генерацией. Спроси хочет ли он что-то скорректировать, или сразу продолжить.

## Шаг 3: Генерация вариантов через Pollinations.ai

Сгенерируй **4 варианта**, вызывая Pollinations.ai через curl. Каждый вариант использует разный seed для разнообразия.

**Формат API:**
```
https://image.pollinations.ai/prompt/{URL_ENCODED_PROMPT}?width=1024&height=768&seed={SEED}&model=flux&nologo=true&negative={URL_ENCODED_NEGATIVE}
```

**Папка для сохранения:** создай `generated-art/` в текущей рабочей директории если её нет.

**Формат имени файла:** `game-art-forge-{timestamp}-v{N}.jpg` (например `game-art-forge-20240508-v1.jpg`)

Запусти все 4 загрузки параллельно для скорости:

```bash
TIMESTAMP=$(date +%Y%m%d-%H%M%S)
OUTDIR="generated-art"
mkdir -p "$OUTDIR"

PROMPT_ENC=$(python3 -c "import urllib.parse; print(urllib.parse.quote('YOUR_PROMPT_HERE'))")
NEG_ENC=$(python3 -c "import urllib.parse; print(urllib.parse.quote('blurry, low quality, watermark, signature, ugly, deformed, NSFW'))")

for SEED in 42 137 256 512; do
  curl -L -s -o "$OUTDIR/game-art-forge-${TIMESTAMP}-v${SEED}.jpg" \
    "https://image.pollinations.ai/prompt/${PROMPT_ENC}?width=1024&height=768&seed=${SEED}&model=flux&nologo=true&negative=${NEG_ENC}" &
done
wait
echo "Готово"
```

Если `curl` недоступен — используй `wget --content-disposition`.

**Таймаут**: если одно изображение генерируется дольше 60 секунд — отметь это, но не блокируй остальные.

## Шаг 4: Отчёт о результатах

После генерации перечисли сохранённые файлы с путями:

```
Сгенерировано 4 варианта в generated-art/:
  - game-art-forge-20240508-123456-v42.jpg
  - game-art-forge-20240508-123456-v137.jpg
  - game-art-forge-20240508-123456-v256.jpg
  - game-art-forge-20240508-123456-v512.jpg

Использованный промпт: "..."
```

Затем спроси: "Какой вариант больше понравился? Могу сгенерировать ещё с другими сидами, скорректировать стиль или изменить сцену."

## Повторная генерация и итерации

Если пользователь просит:
- **"Ещё варианты"** — генерируй ещё 4 с новыми случайными сидами
- **"Ещё похожих на вариант N"** — используй сид того варианта ± небольшие отступы (seed ± 10, ± 20) для похожих результатов
- **"Сделай темнее / ярче / детальнее / и т.д."** — скорректируй промпт и перегенерируй
- **"Измени сцену на X"** — замени тематическую часть промпта и перегенерируй

Сохраняй основу стилевого промпта стабильной между итерациями — визуальная ДНК должна сохраняться.

## Обработка ошибок

- Если изображение не удаётся прочитать (неверный путь, ошибка сети) — пропусти его и сообщи пользователю, не прерывай всё целиком
- Если Pollinations.ai возвращает ошибку (не 200, HTML вместо картинки) — повтори попытку один раз с упрощённым промптом (убери последние 20% дескрипторов)
- Если все 4 провалились — предложи пользователю проверить интернет и попробовать `/game-art-forge` снова

## Справка по Pollinations.ai

- Полностью бесплатно, API-ключ не нужен
- По умолчанию использует модель Flux (высокое качество)
- Типичное время генерации: 15–40 секунд на изображение
- По умолчанию 1024×768; `width` и `height` можно менять свободно
- Портретный режим: `width=768&height=1024`
- Квадрат: `width=1024&height=1024`
- Параметр `seed` делает результаты воспроизводимыми — одинаковый seed + промпт = одинаковое изображение
