# План развития Mafia TMA — Этап 2: Карта и миссии

## 🎮 Концепция

### Визуальная карта — главный экран
Игрок видит **карту города** с кварталами. Его квартал выделен, остальные принадлежат NPC-боссам.

### Стартовые условия
| Параметр | Значение |
|----------|----------|
| 💰 Mafia Coins | 1 000 |
| 🌐 Influence | 10 |
| ⚠️ Wanted Level | 0 |
| 🏘️ Территории | 1 квартал (стартовый) |
| 👤 Бойцы | 1 Капо (универсальный) |

### Механика влияния
| Квартал # | Влияние для захвата |
|-----------|---------------------|
| 1 (стартовый) | 0 (уже есть) |
| 2 | 25 |
| 3 | ~32 |
| 4 | ~40 |
| 5 | ~49 |
| 6 | ~59 |
| 7 | ~70 |
| 8 | 80 |

**Формула:** `threshold(n) = 25 + (n-1) * ~8` (линейный рост до 80 за 8-й квартал)

### NPC Боссы
Каждый квартал принадлежит NPC-боссу с параметрами:
- **Влияние** — определяет "размер" территории
- **Сила** — сложность захвата
- **Цвет** — уникальный для каждого босса

## 📋 Задачи

### Фаза 1: Данные и API (Бэкенд)

#### 1.1 NPC Боссы — модель
```
Boss:
  id: int
  name: str
  color: str  # hex color для карты
  influence: int
  power: int
```

#### 1.2 Territory — расширение
```
Territory:
  ...существующие поля...
  boss_id: int | null  # FK -> Boss, null = свободна
  grid_x: int          # позиция на сетке
  grid_y: int          # позиция на сетке
  neighbors: list[int] # ID соседних территорий
```

#### 1.3 Формула влияния
```python
def influence_threshold(territory_index: int) -> int:
    """Порог влияния для захвата N-го квартала.
    1-й = 25, 8-й = 80, линейная интерполяция.
    """
    if territory_index <= 1:
        return 25
    if territory_index >= 8:
        return 80
    return round(25 + (territory_index - 1) * (80 - 25) / 7)
```

#### 1.4 API эндпоинты
```
GET    /map/                  — карта всех территорий с боссами
GET    /territories/{id}/     — детали района + миссии внутри
POST   /territories/{id}/capture — начать захват
GET    /territories/{id}/missions — миссии в районе (кружки)
```

### Фаза 2: Визуал карты (Фронтенд)

#### 2.1 Компонент карты города
- SVG или CSS Grid сетка кварталов
- Цвета по боссам (🟢 мой, 🔴🔵🟡 NPC)
- Tap на квартал → навигация к экрану района

#### 2.2 Экран района
- Заголовок с названием
- SVG карта с кружками миссий
- Tap на кружок → экран миссии
- Кнопка "Захватить" с проверкой влияния

#### 2.3 Экран миссии
- Описание, требования, награда
- Выбор персонажа (если > 1)
- Кнопка "Начать"

#### 2.4 Bottom навигация
```
🗺️ Карта  🏪 Магазин  👤 Бойцы  ❓ Помощь
```

#### 2.5 Топ-бар ресурсов
```
💰 1000  |  🌐 25  |  ⚠️ 0
```

### Фаза 3: Игровой цикл (Геймплей)

#### 3.1 Запуск миссии
1. Выбор персонажа → POST `/missions/{id}/start/`
2. Таймер на клиенте (duration из БД)
3. Результат: POST `/user_missions/{id}/complete/`
4. Начисление наград (money, influence, wanted)

#### 3.2 Пассивный доход
- Фоновая задача каждые 10 мин
- Territory → money + influence
- Отображение "Доход: +50💰/тик"

#### 3.3 Захват территории
1. Проверка влияния >= threshold
2. Миссия на 3 слота (hard)
3. При успехе → territory.boss_id = null → user
4. Пассивный доход включается

## 🚀 Порядок реализации

1. **NPC Boss модель + миграция** → seed 8 боссов
2. **Territory grid_x/y + neighbors** → seed 8 кварталов
3. **API `/map/`** → отдаёт карту с боссами
4. **Компонент карты (SVG)** → цветные кварталы
5. **BottomNav** → 4 кнопки (Карта, Магазин, Бойцы, Помощь)
6. **Топ-бар ресурсов** → sticky header
7. **Экран района** → кружки миссий
8. **Запуск миссии** → таймер → награда
9. **Формула влияния** → проверка при захвате
10. **Анимации + Telegram тема**
