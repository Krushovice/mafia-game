## 🔴 Приоритет 0: Критичные баги

### Баг 1: `reward_money` миссий = 0
**Симптом:** В dashboard миссии показывают `reward_money: 0`

**Причина:** `MissionService.refill_missions` создаёт `UserMission` без переноса наград из шаблона `Mission`

**Файл:** `src/services/mission_service.py` — метод `refill_missions`

**Решение:**
```python
# При создании UserMission из шаблона:
user_mission = UserMission(
    user_id=user_id,
    mission_id=template.id,
    reward_money=template.reward_money,  # ← добавить
    reward_influence=template.reward_influence,  # ← добавить
    wanted_increase=template.wanted_increase,  # ← добавить
    ...
)
```

---

### Баг 2: `/territories/` возвращает пустой список
**Симптом:** Dashboard показывает 0 территорий, хотя в БД 5 штук

**Причина:** Endpoint `GET /territories/` возвращает только территории пользователя, а их нет

**Файл:** `src/api/routers/territory.py` — `list_territories`

**Решение:**
- Вернуть список всех территорий + флаг `is_mine` для каждой
- Добавить поле `boss` (NPC владелец) для не-захваченных
- Для старта: 1 территория принадлежит игроку, остальные — NPC

---

### Баг 3: Нет стартовой территории у игрока
**Симптом:** При регистрации игрок не получает квартал

**Решение:**
- В `_create_starter_package` добавить привязку к 1-й территории
- Создать `UserTerritory` при регистрации

---

### Баг 4: Нет связи между экранами
**Симптом:** BottomNav не протестирован, не все экраны доступны

- Проверить все роуты в `router-provider.tsx`

## 🟡 Этап 2: Карта и миссии (План пользователя)

> Полная документация: [PLAN_PHASE_2.md](PLAN_PHASE_2.md)

### Концепция
- **Главный экран = Карта города** с цветными кварталами
- 🟢 Мой квартал | 🔴🔵🟡 Кварталы NPC боссов
- **Топ-бар:** 💰 1000 | 🌐 25 | ⚠️ 0
- **BottomNav:** 🗺️ Карта | 🏪 Магазин | 👤 Бойцы | ❓ Помощь
- **Приближение района:** увеличенный вид с кружками миссий
- **Клик на миссию:** детали → выбор бойца → старт → награда

### Механика влияния
| Квартал # | Влияние для захвата |
|-----------|---------------------|
| 1 (стартовый) | 0 (уже есть) |
| 2 | 25 |
| 3 | ~32 |
| 4 | ~40 |
| 5 | ~49 |
| 6 | ~59 |
| 7 | ~70 |
| 8 | 80 |

**Формула:** `threshold(n) = 25 + (n-1) * 55/7`

### Формула влияния
```python
def influence_threshold(territory_index: int) -> int:
    if territory_index <= 1: return 25
    if territory_index >= 8: return 80
    return round(25 + (territory_index - 1) * (80 - 25) / 7)
```

### Порядок реализации Этапа 2
1. NPC Boss модель + миграция → seed 8 боссов
2. Territory grid_x/y + neighbors → seed 8 кварталов
3. API `/map/` → отдаёт карту с боссами
4. Компонент карты (SVG) → цветные кварталы
5. BottomNav → 4 кнопки (Карта, Магазин, Бойцы, Помощь)
6. Топ-бар ресурсов → sticky header
7. Экран района → кружки миссий
8. Запуск миссии → таймер → награда
9. Формула влияния → проверка при захвате
10. Анимации + Telegram тема

**Оценка:** ~15-20 часов
